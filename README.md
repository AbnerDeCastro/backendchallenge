# Backend Challenge — Jungle Gaming

Backend application developed as part of a technical challenge, using NestJS and TypeScript.

## 🚀 Technologies

- **[NestJS](https://nestjs.com/)** — Backend framework
- **[TypeScript](https://www.typescriptlang.org/)** — Typed JavaScript
- **[Bun](https://bun.sh/)** — JavaScript runtime and package manager
- **Vitest** — Testing framework

## 📋 Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [Bun](https://bun.sh/)

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AbnerDeCastro/backendchallenge.git
cd backendchallenge
```

### 2. Install dependencies

```bash
bun install
```

### 3. Run the application

```bash
bun run start:dev
```

The application will start in development mode. Check the terminal for the local URL and port.

## 🧪 Testing

Run the test suite using the scripts configured in `package.json`.

```bash
bun run test
```

## 📁 Project Structure

```text
src/       # Application source code
test/      # End-to-end tests
```
